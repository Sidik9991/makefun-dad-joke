One dad joke for make.fun's "Dad Joke Showdown" — a single original joke,
chosen by executable scoring, not by gut feel. Eleven candidates were written
fresh (no classics, no "Hi hungry, I'm dad"), each scored 1–5 against the
judge brief in the brief's own order — dad-at-table voice, pun lands on first
read, freshness, tightness, reads aloud — and the winner is picked at runtime:
gate first (1–200 characters, non-blank), then highest total score, then
fewest bytes as tie-break. The winning line is a couch, a hidden remote, and
a double meaning on "control issues".

## Run it

```sh
node main.ts
```

Writes the winning joke to `/output/entry.txt` (no trailing newline), then
re-reads it and holds it to the gate: 1–200 characters, non-blank, or it
throws.
